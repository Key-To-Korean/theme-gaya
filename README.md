# Gaya

A custom WordPress theme built for [Key to Korean](https://keytokorean.com) by Aaron Snowberger.

- Version: 1.1.0
- Requires PHP: 7.4+ (tested against 8.2)
- Requires at least WordPress: 6.0

## No build process

Gaya was originally scaffolded from [WP Rig](https://github.com/wprig/wprig) and used a Gulp/Babel/node-sass pipeline that compiled a separate `/dev` source folder into this one. That split is gone: **this folder is the theme.** Edit any file here directly and reload the browser — there is nothing to compile, transpile, or minify. This was a deliberate choice, not an oversight: the old dev/build split let this theme and its production copy drift apart for years, which was the direct cause of most of the bugs fixed in the 2026 PHP 8 compatibility pass (see Changelog below). One theme, one copy, on disk and in git.

If page-weight ever becomes a measured problem, a minification pass can be added later as a one-shot script — not a watch process or dev server — without reintroducing a source/output split.

## Structure

- `functions.php` — theme setup, script/style enqueuing, hooks
- `inc/` — Customizer, template tags, template functions, icon functions
- `pluggable/` — swappable features: custom header, lazyload, breadcrumbs, author box, related posts, better widgets, post formats, featured posts (slider/grid)
- `template-parts/` — content loop partials
- `page-templates/` — selectable admin page templates
- `css/`, `js/`, `slick/`, `fonts/`, `images/` — theme assets
- `languages/` — translation files (`.pot` is stale as of this writing; regenerate with `wp i18n make-pot .` via WP-CLI rather than the old `npm run translate`)

## CSS custom properties

`style.css` defines a small `:root` block (`--gaya-grey`, `--gaya-body`) used by a handful of rules elsewhere in the CSS. These used to be generated by the old build's PostCSS step from a JSON config file that no longer exists in this theme; they're now just plain CSS, defined once, like everything else here.

## Companion plugin

Custom post types (Grammar, Vocabulary, Phrases, Reading, Writing, Vocab List) and their admin tooling live in the separate **K2K** plugin (`mu-plugins/k2k`), not in this theme. The theme's `pluggable/post-functions.php` still checks `post_type_exists( 'jkl-grammar' )` to conditionally fold that post type into the main query if present — everything else CPT-related is the plugin's responsibility, not the theme's.

## Known limitations

- `pluggable/post-formats/link.php`'s link-preview detection looks for a bare `<a>` tag with no attributes, which real content never produces — this feature has been non-functional since it was written. Left as-is rather than rebuilt, to avoid scope creep unrelated to the PHP 8 compatibility work.
- No automated tests. Manual verification in Local (with `WP_DEBUG` on) is the current safety net before any change reaches production.

## Changelog

### 1.1.0 (2026)
- PHP 8.0–8.2 compatibility pass: fixed several undefined-function fatals (typos, incomplete renames from an old `wprig_` → `gaya_` migration, a wrong file path), a broken/dead database query in the Better Archives widget, missing Customizer sanitize callbacks, and multiple unguarded array/property accesses that throw warnings under PHP 8.
- Removed dev-only content that was shipping to real visitors: a debug console-logging script enqueued on every page, and placeholder "fake" related-posts content that displayed when a post had no others in its category.
- Retired the Gulp/Babel/node-sass build pipeline; the theme is now edited directly with no build step.
- Deleted confirmed-dead duplicate files (`archive copy.php`, `front-page1.php`, `index.old.php`, orphaned `class-wprig-*` widget/nav-menu copies, unused `jetpack.php`, an unreachable Twenty Twenty comment-walker class, a permanently-shadowed `singular.php`) and a stale unminified `verbose/` build artifact.
- Added a missing `:root` CSS custom-properties declaration so `var(--gaya-grey)`/`var(--gaya-body)` resolve correctly.

### 1.0.3 and earlier
Built on the WP Rig scaffold; see git history for the theme's original multi-year development.
